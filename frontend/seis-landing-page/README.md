# SEIS Landing Page

Smart Electoral Integrity System (SEIS) modern React/Vite landing page.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The design includes:
- Responsive navigation
- Hero with dashboard and phone mockups
- Statistics
- About SEIS
- Dashboard preview
- Features
- How It Works
- Who We Serve
- Contact
- Footer
- React Icons
